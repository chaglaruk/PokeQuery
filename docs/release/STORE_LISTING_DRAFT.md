# Store Listing Draft

**App Name:** PokeQuery: Safe Search Strings  
**Short Description:** Build safe, review-ready Pokémon GO search strings quickly.  

**Full Description:**  
PokeQuery helps Pokémon GO players organize storage by generating search strings they can review, copy, and paste into Pokémon GO themselves. Build Safe Cleanup and Candy Prep searches, find Hundo/Nundo and PvP candidates, prepare trade reviews, and protect valuable categories before cleanup.

Core search-string generation works locally and does not require a Pokémon GO login. PokeQuery never connects to a Pokémon GO account or private game API and performs no gameplay automation.

The Android app uses the INTERNET permission only for the optional Event Guide, which retrieves a public read-only JSON feed over HTTPS. Preferences, favorites, history, and presets remain local to the device. PokeQuery contains no ads, analytics, or user tracking.

**Key Features:**
- Safe Cleanup and Candy Prep generators with conservative protection rules.
- Hundo, Nundo, PvP, trade-prep, and Expert Builder tools.
- Separate App Language and Search String Language controls.
- English, Turkish, German, Spanish, French, and Italian UI/search-language support where documented.
- Public Event Guide with cached/bundled fallback.
- No Pokémon GO account access, private APIs, ads, analytics, or gameplay automation.
