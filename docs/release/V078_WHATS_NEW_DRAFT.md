## Privacy, safety and listing limits

The text-size preference is saved locally in DataStore. Navigation accessibility adds no data collection, permissions, accounts or telemetry. Existing user-initiated email feedback and the documented public Event Guide refresh remain unchanged. The release privacy and Data Safety drafts therefore require no new collection category for these changes, but the publisher must reconcile the final Console declarations with the final release manifest.

DE/ES/FR/IT Knowledge Base descriptions still contain English fallback. These notes claim no complete catalog translation or verification of unconfirmed localized Pokémon GO tokens. Search generation does not transfer Pokémon or guarantee safe actions.

Store asset recovery is a separate gate: the previously approved 24 files were deleted according to the user on 2026-10-09. Their bytes cannot be claimed preserved. Recover the originals if possible; otherwise recapture and review a complete set after qualified Play-installed production is available. Debug or ADB-only installations cannot replace the required Play-installed provenance. Six Event captures remain pending.
