PokeQuery

Search string generator

Build the search you need without memorising every token.

Pokémon GO has a powerful inventory search language, but combining filters safely gets harder as a query grows. PokeQuery lets you choose a goal, describe a search in Search Assistant, or refine a preset and then review the exact text before copying it.

What PokeQuery does

  • Builds copy-ready search text from tested rules.
  • Keeps protected categories out of safety-focused searches by default.
  • Explains what a query is doing before you use it.
  • Never logs into Pokémon GO or controls the game.

How to use it

  1. Choose the goal closest to what you want to find.
  2. Review the generated search and any risk warning.
  3. Copy it and paste it into Pokémon GO yourself.
  4. Always check the matches before transferring, trading or changing anything.
