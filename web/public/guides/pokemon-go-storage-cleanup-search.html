Storage cleanup

Clean a crowded Pokémon storage list without starting from scratch.

A cleanup filter is useful only if you understand what it can surface. PokeQuery’s Safe Cleanup workflow starts conservatively, excludes protected categories and shows the exact search before you copy it.

Protected by default

The current Safe Cleanup builder protects categories such as shiny, legendary, mythical, Ultra Beast, costume, Shadow, Purified, favourite, lucky, traded and 4★ entries. The exact generated text is visible before use.

A safer cleanup routine

  1. Open Safe Cleanup.
  2. Review the exclusions and refine them if needed.
  3. Read the risk warning.
  4. Copy the search and paste it into Pokémon GO manually.
  5. Inspect the matches before transferring anything.
