Privacy Policy

PokeQuery Privacy Policy

Effective Date: 17 August 2026

1. Product & Developer Identity

App: PokeQuery (offline-first Android application and Web/PWA companion utility).

Developer / Maintainer: chaglaruk

Official Repository: https://github.com/chaglaruk/PokeQuery

Privacy Enquiries: https://github.com/chaglaruk/PokeQuery/issues

PokeQuery is an independent, unofficial companion tool created for Pokémon GO players. PokeQuery is not affiliated with, endorsed by, sponsored by, or associated with Niantic, Inc., Nintendo, or The Pokémon Company.

2. What PokeQuery Does Not Collect

PokeQuery does not require a PokeQuery user account or Pokémon GO login credentials.

PokeQuery does not intentionally transmit to the developer:

  • Pokémon GO usernames, passwords, or authentication tokens
  • Pokémon GO account information or inventory data
  • Locally stored search history, favourites, or personal presets
  • Advertising identifiers, tracking identifiers, or behavioural profiles

PokeQuery does not access private Niantic or Pokémon GO APIs and does not perform gameplay automation or OCR.

3. Local Data Storage

All app settings, search history, favourites, and personal presets are stored locally on your device:

  • Android App: Saved data and preferences are stored locally using Android storage mechanisms, including Jetpack DataStore.
  • Web / PWA: Saved data and preferences are stored locally in browser site storage (LocalStorage).

The PokeQuery developer does not receive, host, or sync these locally stored records.

4. Clipboard Usage

When the user explicitly chooses Copy, PokeQuery places the generated search string on the system clipboard. Clipboard handling is managed by the operating system and browser. PokeQuery does not upload copied search strings to the developer.

5. Network Usage & Public Event Guide Feed

  • Android App: The Android application's feature-level Internet access is used for read-only retrieval of the public GitHub-hosted Event Guide feed. Event data is cached locally for offline reference with bundled fallback data.
  • Web / PWA: The Web/PWA is served through its normal web host and therefore loads application assets over the network. Its feature-level external data retrieval is the public GitHub-hosted Event Guide feed.

For both platforms, PokeQuery does not intentionally include Pokémon GO account data, search history, favourites, presets, or PokeQuery account identifiers in Event Guide requests. Standard HTTP connection metadata, such as IP address and User-Agent, may be processed by GitHub and network hosting providers to serve the request. The developer receives no user analytics or behavioural profiles from these requests.

6. Data Sharing & Sale

PokeQuery does not sell, rent, or monetize user data. PokeQuery does not intentionally share locally stored search queries, favourites, presets, or settings with third-party advertisers or data brokers. Standard HTTP metadata is processed by GitHub as the hosting provider solely to deliver public application and feed files.

7. Secure Data Handling

  • Event Guide feed requests are transmitted exclusively over encrypted HTTPS connections.
  • Android local data is protected by standard Android operating system sandbox permissions and device security mechanisms.
  • Web/PWA local data is protected by standard browser origin-isolation and site-storage protections.
  • PokeQuery integrates zero advertising SDKs, tracking frameworks, or third-party analytics libraries.
  • While reasonable platform protections are utilized, no method of electronic storage or network transmission is completely infallible.

8. Data Retention & Deletion

Locally stored data remains on your device until you choose to remove it:

  • Android: You can delete all locally stored data at any time by clearing PokeQuery app data in Android Settings or by uninstalling the application.
  • Web / PWA: You can delete all locally stored data at any time by clearing site data or cookies in your web browser settings.

Because the developer does not maintain a server-side database of your searches, favourites, or presets, there is no remote user account to delete.

9. Contact & Policy Updates

For privacy enquiries, bug reports, or questions regarding this policy, please open an issue on the official project repository: https://github.com/chaglaruk/PokeQuery/issues.

If material changes are made to PokeQuery's privacy practices, this policy will be updated with a revised effective date.
